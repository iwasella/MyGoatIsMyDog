description: User-specified creative constraints for this gift app.

Keep the gothic “thug life” lettering and dark undertone palette. Lean into an emo aesthetic with silver and peace signs, but keep the humor friendly, understated, and personal.

No roasts, “Baka,” cringey anime references, crosses, repeated middle-school mentions, or self-harm/suicide jokes. Leave memorial material out rather than using it for humor.

If a restaurant memory is referenced, use only the fictional name “Garden of the Olive.”

**Why:** The user refined the original chaotic-teasing brief: they explicitly requested removing roasts and unwanted symbols while keeping the font and dark palette.

**How to apply:** Apply these limits to all new copy, background images, sprites, and animations. Personal references should be occasional discoveries, not repeated exposition.
